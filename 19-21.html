Теория игр — задания 19-21

Разбор прототипов, универсальный шаблон кода и практика

Шаг 1. Конкретная задача (пример)

Условие: Петя и Ваня играют в кучу камней. За один ход можно добавить 1 камень или увеличить кучу в 2 раза. Игра заканчивается, когда камней становится не менее 69. Побеждает тот, кто сделал последний ход. Стартовое количество камней — S (1 ≤ S ≤ 68).

Именно из этого условия берутся все числа: 69 (финиш), +1 и ×2 (ходы), 1…68 (диапазон S).

Шаг 2. Шаблон кода под эту задачу

Одна и та же функция решает все три вопроса. В ней уже подставлены числа из задачи выше:

def game(s, p, end):
    if s >= 69: return p in end
    if p >= max(end): return False
    m = [game(s + 1, p + 1, end), game(s * 2, p + 1, end)]
    return (any if p % 2 == 0 else all)(m)
Что означают переменные:

• s — текущее количество камней.
• p — номер хода. Чётное — Петя, нечётное — Ваня.
• end — список ходов, на которых игра должна закончиться, чтобы победил «наш» игрок.
• m — результаты всех возможных ходов (True — победа, False — поражение).

Построчный разбор шаблона — как мы к нему пришли

1
def game(s, p, end):
Объявляем функцию. Мы хотим проверить: «может ли игрок, чей сейчас ход, гарантированно победить, если в куче s камней, это p-й ход, и победа должна случиться на одном из ходов из списка end». Функция возвращает True (победа возможна) или False (нет).
2
if s >= 69: return p in end
Условие выхода (проверка на финиш). Если камней уже ≥ 69, игра закончена. Мы проверяем, входит ли текущий номер хода p в список end. Если да — значит, победил нужный нам игрок, возвращаем True. Если нет — возвращаем False (игра закончилась, но не на «нашем» ходу).

Пример: если end = [2] (победа Вани на 2-м ходу), а игра закончилась на ходу p = 3 (победа Пети), то 3 in [2] → False. Возвращаем False — Ваня не выиграл.
3
if p >= max(end): return False
Защита от бесконечности. Если мы уже сделали больше ходов, чем максимально нужно (max(end)), а игра так и не закончилась — значит, нужный игрок не смог победить. Возвращаем False и не идём в рекурсию глубже. Эта строка экономит время и не даёт программе уйти в бесконечный цикл.

Пример: если end = [2], а мы уже на 3-м ходу (p = 3), то 3 >= 2 → True. Возвращаем False, потому что нужный игрок (Ваня) должен был победить на 2-м ходу, а не позже.
4
m = [game(s + 1, p + 1, end), game(s * 2, p + 1, end)]
Перебор всех возможных ходов. Из текущей позиции у игрока есть два хода: +1 и *2. Мы вызываем функцию game для каждого из них, увеличивая номер хода на 1 (p + 1). Результаты (True или False) складываем в список m.

Пример: пусть s = 34, p = 0. Тогда m будет содержать результаты для s = 35 (ход +1) и s = 68 (ход *2). Оба этих значения ≥ 35, значит, оба выигрышные для соперника, и m будет [False, False] (потому что следующий игрок сразу выиграет).
5
return (any if p % 2 == 0 else all)(m)
Принимаем решение в зависимости от того, чей ход.

• Если p чётное (p % 2 == 0), значит, сейчас ходит Петя (наш игрок). Ему достаточно хотя бы одного победного хода, поэтому используем any(m).
• Если p нечётное, значит, сейчас ходит Ваня (соперник). Он будет выбирать лучший для себя ход, поэтому Петя победит только если все ходы Вани ведут к победе Пети. Используем all(m).

Запись (any if p % 2 == 0 else all)(m) — это компактный способ сказать: «выбери функцию (any или all) и сразу примени её к списку m».

Шаг 3. Как отвечать на 19, 20, 21 — три разных вызова

Сама функция не меняется. Меняется только то, что мы передаём в неё извне: диапазон S и массив end.

Задание 19 — «Ваня выигрывает за 1 ход»

Что нужно: Петя не выигрывает за 1 ход, но любой его ход ведёт в позицию, где Ваня выигрывает за 1 ход.

Как это выразить в коде:

  • not game(s, 0, [1]) — Петя не выигрывает за 1 ход (иначе game(s, 0, [1]) вернуло бы True).
  • game(s, 0, [2]) — игра заканчивается на 2-м ходу (ход Вани) победой Вани.
# 19. Минимальное S, при котором Петя не выигрывает за 1, а Ваня — за 1
ans19 = [s for s in range(1, 69)
         if not game(s, 0, [1]) and game(s, 0, [2])]
print(min(ans19))   # → 34

Задание 20 — «Петя выигрывает за 2 хода»

Что нужно: Петя не выигрывает за 1 ход, но выигрывает своим 2-м ходом (то есть игра заканчивается на 3-м ходу).

Как это выразить в коде:

  • game(s, 0, [3]) — игра закончилась на 3-м ходу (ход Пети) победой Пети.
  • not game(s, 0, [1]) — но Петя не может победить раньше (за 1 ход).
# 20. Два наименьших S, при которых Петя выигрывает за 2, но не за 1
ans20 = sorted([s for s in range(1, 69)
                if game(s, 0, [3]) and not game(s, 0, [1])])
print(ans20[:2])   # → [17, 33]

Задание 21 — «Ваня выигрывает за 1 ИЛИ 2 хода, но не за 1»

Что нужно: Ваня гарантированно выигрывает своим 1-м или 2-м ходом. Но стратегии «выиграть за 1 ход» у него нет.

Как это выразить в коде:

  • game(s, 0, [4]) — игра заканчивается на 4-м ходу (ход Вани) победой Вани.
  • not game(s, 0, [2]) — но Ваня не может выиграть на 2-м ходу (за 1 ход).
# 21. Минимальное S, при котором Ваня выигрывает за 2 хода, но не за 1
ans21 = [s for s in range(1, 69)
         if game(s, 0, [4]) and not game(s, 0, [2])]
print(min(ans21))   # → 32
Логика массива end:
• end = [1] — победа Пети на 1-м ходу.
• end = [2] — победа Вани на 2-м ходу (свой 1-й ход).
• end = [3] — победа Пети на 3-м ходу (свой 2-й ход).
• end = [4] — победа Вани на 4-м ходу (свой 2-й ход).

То есть в end указывается абсолютный номер хода, на котором должен победить «наш» игрок.

Логика без кода — «на пальцах»

Чтобы понимать, что делает код, полезно один раз пройти путь руками. Идём от финиша к старту.

Шаг A. Где Петя побеждает мгновенно?

Петя ходит первым. Если ход +1 или ×2 сразу даёт ≥ 69, Петя выигрывает моментально.

  • S + 1 ≥ 69 → S ≥ 68
  • S × 2 ≥ 69 → S ≥ 35

Значит, 35…68 — это «горячая зона»: тот, кто в ней оказался, сразу выигрывает.

Шаг B. Где Петя гарантированно проиграет?

Это позиции, из которых нельзя сразу выиграть, а любой ход дарит сопернику «горячую» позицию. Проверим S = 34:

  • ход +1 → 35 (выигрышная для соперника).
  • ход ×2 → 68 (тоже выигрышная).

Оба хода плохие → 34 — проигрышная позиция. Дальше проигрышными будут 17, 8, 4, 2, 1 (получаются делением на 2 и вычитанием 1 с конца).

Шаг C. Где Петя выигрывает за 2 хода?

Это позиции, из которых есть хотя бы один ход в проигрышную. Например, S = 33: ход +1 → 34 (проигрышная для Вани). Значит, Петя выигрывает за 2 хода.

Что такое any и all?

Это встроенные функции Python для работы со списком True/False.

  • any([False, True, False]) → True (есть хотя бы один True).
  • all([True, False, True]) → False (не все True).

Почему в игре именно так: если сейчас ходит Петя (чётный p), ему достаточно одного победного хода → any. Если ходит Ваня (нечётный p), Ваня будет мешать, и Петя победит только если все ходы Вани ведут к победе Пети → all.

Основные прототипы задач

Проанализировав базу ФИПИ, можно выделить 3 основных типа условий. Шаблон кода остаётся тем же, меняются только 2-3 строки.

Прототип 1: Одна куча, камни прибывают (s >= N)

Пример: За ход можно добавить 1 камень или увеличить кучу в 2 раза. Игра идёт до тех пор, пока камней не станет не менее 69.

Код для этого прототипа

def game(s, p, end):
    if s >= 69: return p in end
    if p >= max(end): return False
    m = [game(s + 1, p + 1, end), game(s * 2, p + 1, end)]
    return (any if p % 2 == 0 else all)(m)

Построчный разбор

1
def game(s, p, end):
Объявляем функцию. s — камни, p — ход, end — на каком ходу должен быть выигрыш.
2
if s >= 69: return p in end
Условие выхода. Если камней 69 или больше, игра окончена. Проверяем, входит ли номер текущего хода p в список end. Если да — возвращаем True (победа).
3
if p >= max(end): return False
Защита от бесконечности. Если мы сделали больше ходов, чем нужно (max(end)), а игра не кончилась — значит, нужный игрок не смог победить. Возвращаем False.
4
m = [game(s + 1, p + 1, end), game(s * 2, p + 1, end)]
Перебор ходов. Запускаем рекурсию для двух ходов: +1 и *2. Результаты (True или False) складываем в список m.
5

Выбор стратегии. Если p чётное (Петя) — используем any(m) (достаточно одного победного хода). Если нечётное (Ваня) — all(m) (Петя победит, только если Ваня не сможет помешать ни одним ходом).
Прототип 2: Одна куча, камни убывают (s <= N)

Пример: За ход можно убрать 3 камня, убрать 8 камней или уменьшить кучу в 3 раза (округление вниз). Игра идёт до тех пор, пока камней не станет не более 16.

Код для этого прототипа

def game(s, p, end):
    if s <= 16: return p in end
    if p >= max(end): return False
    m = [game(s - 3, p + 1, end), game(s - 8, p + 1, end), game(s // 3, p + 1, end)]
    return (any if p % 2 == 0 else all)(m)

Ограничение ходов. Отсекаем ветки, где игра затянулась дольше нужного.
4

Перебор ходов. Здесь три возможных хода. //3 — это целочисленное деление (округление вниз), как и сказано в условии.

Прототип 3: Две кучи (a + b >= N)

Пример: В первой куче 13 камней, во второй S. За ход можно добавить 3 камня в любую кучу или увеличить любую кучу в 2 раза. Игра кончается, когда сумма камней станет не менее 135.

Код для этого прототипа

def game(a, b, p, end):
    if a + b >= 135: return p in end
    if p >= max(end): return False
    m = [
        game(a + 3, b, p + 1, end), game(a * 2, b, p + 1, end),
        game(a, b + 3, p + 1, end), game(a, b * 2, p + 1, end)
    ]
    return (any if p % 2 == 0 else all)(m)

3

Ограничение ходов. Всё без изменений.

Выбор стратегии. Логика чётности не меняется.

Задача 3 (Две кучи)
Задание 19. Два игрока, Петя и Ваня, играют в следующую игру. Перед игроками лежат две кучи камней. Игроки ходят по очереди, первый ход делает Петя. За один ход игрок может:
– добавить в одну из куч (по своему выбору) 3 камня;
– увеличить количество камней в одной из куч (по своему выбору) в 2 раза.

Например, пусть в одной куче 20 камней, а в другой 30 камней; такую позицию в игре обозначим (20, 30). Тогда за один ход можно получить любую из четырёх позиций: (23, 30), (20, 33), (40, 30), (20, 60).

Для того чтобы делать ходы, у каждого игрока есть неограниченное количество камней. Игра завершается в тот момент, когда суммарное количество камней в двух кучах становится не менее 135. Победителем считается игрок, сделавший последний ход, то есть первым получивший такую игровую позицию, при которой в двух кучах суммарно 135 камней или больше. В начальный момент в первой куче было 13 камней, во второй куче – S камней; 1 ≤ S ≤ 121.

Будем говорить, что игрок имеет выигрышную стратегию, если он может выиграть при любых ходах противника.

Известно, что Ваня выиграл своим первым ходом после неудачного хода Пети. Укажите минимальное значение S, при котором такая ситуация возможна.

Задание 20. Для игры, описанной в задании 19, найдите два наименьших значения S, при которых у Пети есть выигрышная стратегия, причём одновременно выполняются два условия:
– Петя не может выиграть за один ход;
– Петя может выиграть своим вторым ходом независимо от того, как будет ходить Ваня.
Найденные значения запишите в ответе в порядке возрастания.

Задание 21. Для игры, описанной в задании 19, найдите наименьшее значение S, при котором одновременно выполняются два условия:
– у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети;
– у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом. 
def game(a, b, p, end):
    if a + b >= 135: return p in end
    if p >= max(end): return False
    m = [
        game(a + 3, b, p + 1, end), game(a * 2, b, p + 1, end),
        game(a, b + 3, p + 1, end), game(a, b * 2, p + 1, end)
    ]
    return (any if p % 2 == 0 else all)(m)

# 19: Ваня выигрывает за 1 ход
print(min(s for s in range(1, 122) if not game(13, s, 0, [1]) and game(13, s, 0, [2])))

# 20: Петя выигрывает за 2 хода (на 3-м ходу)
print(sorted([s for s in range(1, 122) if game(13, s, 0, [3]) and not game(13, s, 0, [1])])[:2])

# 21: Ваня выигрывает за 1 или 2 (на 4-м), но не за 1
print(min(s for s in range(1, 122) if game(13, s, 0, [4]) and not game(13, s, 0, [2])))
